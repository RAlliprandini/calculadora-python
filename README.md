# 🧮 Calculadora em Python

Calculadora com interface gráfica feita com **Tkinter** (já vem com o Python, sem dependências).

## Recursos
- Tema escuro com botões arredondados e efeitos de hover/clique
- Prévia do resultado enquanto você digita
- Operações: `+ − × ÷`, porcentagem `%`, troca de sinal `±` e apagar `⌫`
- Avaliação segura das expressões (sem `eval`)
- Suporte ao teclado

## Como rodar
```bash
python calculadora.py
```

## Atalhos de teclado
| Tecla | Ação |
|---|---|
| `0-9`, `.` ou `,` | Números |
| `+ - * /` | Operações |
| `Enter` ou `=` | Resultado |
| `Backspace` | Apagar |
| `Esc` ou `Delete` | Limpar tudo |
| `Ctrl+C` | Copiar resultado |
